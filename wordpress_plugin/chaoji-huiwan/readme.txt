== Description ==

【钞机汇玩】是一款专为 WordPress 设计的短视频与图集无水印提取工具插件。
通过统一短代码 `[chaoji_video_parser]`，可将全功能提取器一键嵌入任意页面或文章。

核心功能特性：
* 12 大主流平台全自动聚合识别（抖音、快手、小红书、B站、TikTok、X推特、YouTube、剪映/即梦、今日头条、豆包、红果/番茄、视频号）。
* 响应式 HTML5 高清在线播放器（支持全屏、画中画、倍速播放）。
* 突破微信 50MB 内存限制，浏览器原生千兆高速下载。
* 高清图集多图瀑布流网格展示与单图下载。
* 本地浏览器 localStorage 历史记录保存与管理。
* 每日免费提取额度限制与卡密兑换系统（与微信小程序完全打通）。
* 自定义广告位支持（可嵌入 Google AdSense 或自定义推广横幅）。

== Installation ==

1. 下载 `chaoji-huiwan.zip` 压缩包。
2. 登录 WordPress 管理后台，进入「插件」->「安装插件」->「上传插件」，选择该压缩包并点击「现在安装」。
3. 激活插件。
4. 新建一个 WordPress 页面（例如页面标题命名为“无水印视频提取神器”），在正文中添加短代码：
   `[chaoji_video_parser]`
5. 发布页面，即可在前台直接使用完整功能！
